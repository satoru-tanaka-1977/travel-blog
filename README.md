# Travel Blog

CODEJUMP 上級編の「Travel Blog」課題として制作しているWebサイトです。

## 概要

HTML・CSSを使用して、旅行ブログをテーマとしたWebサイトを制作しています。

CODEJUMPの課題を通して、HTML・CSSのコーディングスキルを高めるとともに、レスポンシブ対応やWebサイトのレイアウト設計について学習しています。

## 学習内容

- HTMLによるWebサイトの構造設計
- CSSによるレイアウト・デザイン
- Flexboxを使用したレイアウト
- 疑似要素（::before / ::after）を使用した装飾
- ホバーアニメーション
- レスポンシブ対応
- Git / GitHubによるバージョン管理

## 使用技術

- HTML5
- CSS3
- Git
- GitHub
